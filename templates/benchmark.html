Methodology

Each URL was looked up in the Wayback Machine CDX API to get the most recent 200-status snapshot. That snapshot was then fetched via plain HTTP (no JavaScript execution) and separately via Browserbase (a full Chromium browser in the cloud). A page is considered usable if it contains more than 400 characters and does not match known bad-page markers (domain-for-sale, 404 banners, redirect notices, etc.).
